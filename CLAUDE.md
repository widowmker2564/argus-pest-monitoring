**All project instructions live in [`AGENTS.md`](AGENTS.md).** Read it now,
in full, before doing anything in this repository. It covers what the system
is, which document to read for which area, the working conventions, the
security rules, and the project framing that is easy to get wrong.

kept thin: two files that both claim to hold the rules will drift apart, and
then neither can be trusted.

The same applies to any other agent tool with its own convention — point it at
`AGENTS.md` rather than copying the content.
